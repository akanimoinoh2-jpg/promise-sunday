# Promise Sunday — Data Analyst Portfolio

A responsive React portfolio built with Vite and React Router. It includes overview, projects (`/projects`), project detail (`/projects/:slug`), about, services, and contact routes. Legacy `/work` URLs redirect to the matching project routes.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

## Local portfolio materials

The `public/assets` directory contains the supplied portrait, dashboard screenshots and recording, CV, source workbook, and supporting project reports. Project descriptions use the claims and figures visible in those source materials.

The contact form prepares an email in the visitor's mail app; it does not submit to a server or store messages.
